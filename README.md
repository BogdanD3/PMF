* **C** — zadaci i vježbe iz programiranja
* **Java** — zadaci i vježbe iz programiranja

### Druga godina

* **C++** — zadaci i vježbe iz programiranja
* **Java** — kasniji predmeti, uključujući **distributivne sisteme, niti (threadove) i konkurentno programiranje**
